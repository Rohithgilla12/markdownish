Why this exists

Every markdown editor
was built for writers.

Markdown was invented by a developer, for developers — and then the entire editor market that grew up around it decided to aim at novelists. Beautiful tools, all of them. None of them know what a CLAUDE.md is.

But the people writing the most markdown today aren't blogging. They're editing agent context — CLAUDE.md, AGENTS.md, SKILL.md, specs, plans, PRDs — all day, between agent runs. Opening a full IDE to fix three lines in a config file never made sense.

So this is the small, purpose-built thing for that loop. It treats your agent files as first-class, watches the disk for when an agent rewrites them, and gets out of the way. One folder at a time.

01

Your context files, pinned

CLAUDE.md, AGENTS.md, SKILL.md, README.md auto-pin to the top of the sidebar the moment they exist. The files you reach for are never more than one glance away.

02

Reloads when the agent writes

A file watcher sees the moment Claude Code rewrites the open file. No unsaved work? It reloads silently. Mid-edit? It asks first — it never clobbers you.

03

md . from any terminal

One shell alias opens the current folder from wherever you are. The editor is a keystroke away from the place you already work — your prompt.

The loop

md .  and you're in.

↪ from your prompt

Type md .

From any project directory, the folder opens — agent files already pinned at the top.

↪ the agent runs

Claude Code writes

It rewrites a section of the file on disk. The watcher catches it within a debounced beat.

↪ back to you

It reloads, beautifully

You read the new version in clean prose, make your edit, and ⌘S. The loop closes.

Vellum & Ink

Typography is the
whole point.

Warm walnut surfaces — never zinc, never slate. Cream ink. A single copper foil accent that does all the emphasis so nothing else has to shout. Every color lives in OKLCH so the lightness ramps stay even across five themes.

The rendered preview should look genuinely good to read — generous line height, a measured column, a drop cap to open. The kind of page you'd happily spend an afternoon in.
